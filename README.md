# PZ Mobil

Handy-App (PWA) zur Projektzentrale: Einträge unterwegs erfassen und per Mail an die Projektzentrale schicken.

Adresse: https://carrion13-tech.github.io/pz-mobil/

Die App enthält keine Daten. Kunden und Projekte kommen über den Einrichtungs-Link aus der Projektzentrale
(Einstellungen → Handy-App) und bleiben nur auf dem Handy gespeichert.
